# Blockin

A custom-built voxel crafting and game project featuring a clean, modern UI, inventory management, and block-building mechanics. Powered by a custom launcher capable of compiling and launching the game seamlessly.

---

## Features
* **Integrated Launcher:** Automatically compiles and launches the game right out of the box.
* **Modern UI & HUD:** Custom-designed inventory and crafting grids with clean panel styling.
* **Voxel Mechanics:** Classic block placement, breaking, and material management.
* **Community Driven:** Open for community code contributions, pull requests, and collaborative development.

## Getting Started
1. Clone or download the repository.
2. Run the launcher to compile the source code.
3. Launch *Blockin* and start building!
